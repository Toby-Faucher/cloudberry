# What makes a UI read as AI-made (Nov 2026), and where Cloudberry still shows it

Basis: about 18 sources. X posts mostly came through search snippets, because x.com returns 403. Reddit blocks the crawler, so there are no Reddit sources. Hacker News was read through the Algolia API. The counts below are "how many of my sources name it". They are not measured frequencies. The only real measurement is Krebs's scan of 1,590 Show HN sites (Apr 2026). It found 22% of sites hit 4 or more patterns, but it does not give per-pattern counts. Sailop (Apr/Oct 2026) found no web-wide surge in gradients or fonts, so these are recognition cues, not statistics.

## 2. Less-obvious tells (only where sources back them)

- **Second-order "tasteful" defaults.** The new tells are what models produce once told to avoid purple. These are cream + terracotta ("the Claude look"), near-black with one acid accent, tinted near-black (`#111`), mono labels, and **meta joined with middle dots "A · B · C"**. Sources: Anthropic's own frontend-design skill text (calibration list), [avoid-ai-design](https://github.com/funboy322/avoid-ai-design), and a [Muzli review of Claude Design](https://feed.muz.li/?p=201602) ("cream backgrounds, serif headings, and terracotta accents"). Cited by ~4. This is the most relevant tell for Cloudberry.
- **Status strings and status dots** ("Live · v2.4 · Synced", a pulsing dot beside static data): unslop-ui U6/U10, vibemole. ~2.
- **Botsplaining captions and subtitles that restate the title**: unslop-ui U3/U4.
- **Muted grey body text, barely passing contrast in dark mode**: Krebs, scalr #3, avoid-ai-design. ~3.
- **The same 3/6-up grid, same heading length, same two-line description**: vibemole, scalr #12.
- **Spacing**: the sources disagree. scalr says *inconsistent* spacing is the tell. unslop-ui *enforces* a 4/8 scale and flags `gap: 7px`. thecrit says *uniform* padding is the tell. Take-away: the tell is spacing that encodes no grouping, not the grid itself.
- **Not supported by sources**: toast styles, default focus rings and stock empty states. I found no source naming them; scanaislop only covers shipped placeholder text. Don't spend effort on these as "AI tells".

## 3. Cloudberry audit

Evidence comes from `phase3-shots/3-main-*`, `4-combo-desktop-light.png` and the code in `web/src`.

1. **Warm off-white + orange, i.e. the "Claude look" (tell §2, high risk).** `app.css` sets `--bg: #f5f4f2` and `--surface: #fff` with a `#F0912B` accent. In the light shots this reads as Anthropic cream + clay. Dark mode is `#131211` with one orange accent, which is the "near-black + one accent" default. *Fix:* commit to the fruit. Use a saturated, non-neutral page colour: a deep cloudberry-leaf green, or a butter-yellow field with the amber on top. Keep white only as the die-cut stroke. Give dark mode a real hue (a night-sky plum or forest), not tinted black.
2. **The sticker look doesn't show.** The die-cut `--die-cut` (4px `#fffdf9`) is used on only ~5 elements: the pause button, combo, title card and now-playing art (`NowPlaying.svelte:266,366`, `ComboMeter`, `TitleCard`, `+page.svelte:228`). On the white `--surface` card it is invisible (3-main-desktop-light: the art and pause button have no visible outline). Everything else uses the generic `--shadow: 0 6px 16px -8px` soft drop (`Listeners`, `ChatPanel`, `Toast`, `+page.svelte:179`), which is tell #3. *Fix:* put stickers on a coloured ground so the white cut reads. Swap the soft blurred shadows for one flat, offset, same-hue darker "sticker shadow" (the sticker world earns this; neobrutalist black does not). Give the queue rows and library tiles die-cut art too.
3. **A standard three-pane card layout** (tells #3/#12). A rounded left card, a list column and a right drawer, all at `--r-lg`, look like a dashboard template. Recently played and Library are identical 2-up grids of the same row (`Library.svelte`). *Fix:* break the symmetry. Make the now-playing sticker oversized and overlapping its card edge, slightly rotated (1–3°). Show Recently played as a shelf of tilted sleeves, not a second copy of the list. Drop the Library grid's equality: show the most recent big and the rest small.
4. **Count badge after every section title** (`.section-title small` in `app.css`: "Up next 4", "Recently played 3", "Library 3"). This is template chrome (tell #5). *Fix:* remove them, or keep the count only on Up next and render it as part of the heading ("4 up next").
5. **Status chips "● LIVE", "● SYNC 14 ms", "4 HERE"** (`.chip`, `.pip` in `app.css`; `Hud.svelte`). These are unslop U6/U10 exactly: uppercase tracked labels plus status dots, and a dev metric (sync ms) shown to 4 coworkers. *Fix:* delete SYNC (show it only when sync degrades). Fold "4 here" into the avatar stack. Turn LIVE into a drawn on-air sign or a cloudberry that pulses with the beat, not a pip chip.
6. **Lucide everywhere** (12 components: `HeaderTools`, `Queue` with `GripVertical`, `NowPlaying`, `Toast`, `ChatPanel`, `Avatar`'s `Crown`, and others) (tell #8). In the shots the header bell, keyboard and chat icons are thin 1.5px outline strokes next to chunky Fredoka. That stroke mismatch is the giveaway. *Fix:* draw a small custom set of 10–12 chunky filled icons with 2.5–3px rounded strokes, matching the berry wordmark. Do the crown, skip, play/pause and chat bubble first; they are the most visible.
7. **Emoji reactions in identical grey square tiles** (`ReactionBar.svelte`, `REACTIONS` in `types.ts`) (tells #9, #3). The screenshots show tofu boxes, so headless Chromium lacks an emoji font. Real users may see platform emoji that clash across OSes. *Fix:* draw six reaction stickers (flame, laugh, heart, clap, party, zzz) as die-cut SVGs and lay them out like a sticker sheet, not a toolbar.
8. **Middle-dot meta "William · 0:30"** on every row (`Queue.svelte:106`, `Library.svelte:53`, `AddLink.svelte:66-68`) (tell §2). *Fix:* make the duration a small rounded tab on the art, and keep the adder as the avatar alone.
9. **Inter + Fredoka.** Inter is the #2 tell. Fredoka is fine for a game, but it is the go-to "playful Google font". *Fix:* keep Fredoka for the display face. Replace Inter for UI text with something with more character that still reads at small sizes (e.g. Nunito, Rubik, or a licensed game-UI face). At minimum stop using `cv11`/`ss01` Inter for chips and titles.
10. **Chat drawer as a grey event log** (`ChatPanel.svelte` `.event`). In the shots the panel is ~30 rows of muted "Toby joined / Toby left" in small grey Inter. That is the muted-grey-text tell (§2), and it reads like a generated activity feed. *Fix:* collapse consecutive joins and leaves ("Toby popped in and out ×4"). Render events as tiny inline stickers between real messages, and give the empty chat a drawn moment instead of a list.
11. **The Halo/Bloom/Bars segmented pill** (`ModeSwitch.svelte`) is a shadcn `Tabs` lookalike (tell #4). *Fix:* use three chunky toggle buttons with tiny visual previews, or a dial.
12. **Generic copy**: "Paste a YouTube link", "Message the room", and "Every track anyone adds lands here, ready to queue again" (`Library.svelte:17`) all read neutral. *Fix:* write copy in the house voice of four coworkers ("Drop a song in", "Say something to the room"). The rule: someone outside the team couldn't have written it.
13. **Placeholder art** is a green gradient square with a highlight circle (fixture thumbnails, so possibly test-only). If any gradient fallback ships, it is a gradient-wash tell. The `Art.svelte` initial-letter fallback is fine. Better still, give each track a coloured berry sticker.

Not a tell here: the motion. Combo flings, smear and pokes all respond to actions, which is exactly what the Anthropic skill endorses. The **NEXT** tag and the pause-button lip already fit the game world.

## 4. What reads as human-made (from sources)

- **Commit to one world and spend everything on it.** "when torn between refined and committed, commit" (impeccable craft-floor). Override the defaults, don't soften them.
- **Intentional asymmetry**: offset and overlap elements, mix large and small, 1–3° off-grid ([recodehive #971](https://github.com/orgs/recodehive/discussions/971), 2026-01-26; [Behance trends 2026](https://www.behance.net/gallery/239027109/Design-Trends-2026)). It has to look deliberate: "make it slightly more visible if an imperfection reads as a mistake."
- **One dominant element per view**, not equal emphasis everywhere (vibemole, thecrit).
- **Custom, drawn iconography and illustration**, "Real illustration or none" (impeccable). Avoid sketchy fake-hand-drawn SVG.
- **Opinionated type**: one expressive face, deliberate weight and size contrast (recodehive; Anthropic skill).
- **Real content and real voice**: "Start With Content, Not Layout"; copy "the way people actually speak" (recodehive); real data instead of fake stats (scanaislop).
- **Spacing that encodes grouping** (tight within a group, generous between), not one gap everywhere (thecrit: 8/24/48).
- **Motion only where it shows state or answers an action** (Anthropic skill; vibemole).
