## Direction contract

THESIS: Cloudberry is a small shared desk radio, so the screen is its faceplate: one raised deck object holding the playing track, keys and readouts, beside a quiet ruled list area. Refuses the three-equal-cards dashboard and the sticker/game look it replaces.

OWN-WORLD: Cool aluminium grey (light) / graphite (dark) chassis, off-white module faces, 1px rules, 4–6px radii, one hot cloudberry orange used only for the play key, LEDs, the playhead and own-message ticks. Host Grotesk for UI, Martian Mono for labels/numbers/times (tabular), Doto dot-matrix only for big readouts. Monochrome 1.75px square-terminal pictograms.

STORY: In one glance: what is on (title + art + on-air LED), how far in (dot-matrix readout + segmented meter), who is here (listener tiles with LEDs), what is next (numbered 01, 02 rows).

FIRST VIEWPORT: Header strip (brand mark, sync meter, next-in countdown, listeners, keys); left deck (screen with art + visualizer, title, readout, meter, transport keys + fader, reaction keys, mode switch); right ruled lists (add slot, queue, just played, library); chat docked as a device log.

SIGNATURE: Physical transport: keys that depress 1px with a collapsing bottom edge, a hold-to-skip key that fills from the bottom, and a fader for volume; digits that roll in the countdown.

RISK: Becoming a costume of an instrument (fake screws, grilles); keep controls standard buttons/inputs and spend the world only on type, palette, density and the key/readout move.
